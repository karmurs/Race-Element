📁 결과 파일 불러오기

ACC 결과 JSON 파일을 여기로 드래그하거나 클릭해서 선택하세요
위치: 문서\Assetto Corsa Competizione\Results  ·  폴더째 끌어다 놓아도 됩니다 (UTF-16 자동 처리)
⚠ ACC는 매 레이스 후 Race.json을 덮어쓰므로, 각 라운드가 끝날 때마다 불러와 주세요. 한번 불러온 결과는 앱이 계속 기억합니다.

📺 라이브 (게임 실시간)

게임의 실시간 순위를 보려면 live-bridge.py를 실행하고 "라이브 연결"을 누르세요.
설정 방법: 문서\Assetto Corsa Competizione\Config\broadcasting.json에서 updListenerPort=9000 (udp가 아니라 upd — ACC의 오타!), connectionPassword="asd" 지정 후 게임 재시작 → python live-bridge.py. 포트는 실제 세션(트랙 위)에서 열립니다.

⚙️ 포인트 설정

오프라인 챔피언십은 게임이 팀명 칸의 이름을 리더보드에 표시합니다 (AI 챔피언십이면 끄세요)
